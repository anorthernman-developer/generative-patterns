# Privacy

This is a static site. It has **no trackers, no analytics, no adverts and no cookies**, and it has no server of its own.

- **Your sounds** (any samples you drop in) are processed in your browser and are never uploaded.
- **Your Gemini key**, if you choose to paste one, stays in your browser. It is saved in this browser's `localStorage` (key `sr12.geminiKey`, shared with the other tools on this site), sent only to Google (`generativelanguage.googleapis.com`) with the requests you make, and never sent to us. Press **FORGET KEY** to delete it, or clear this site's data in your browser. Google's own terms apply to those requests.
- **Settings and presets** you save are kept in `localStorage` in your browser.
- **Fonts** are embedded in the page, so no font requests are made to anyone.
- **Hosting:** GitHub Pages may keep standard server logs (such as IP address and time of request), as any web host does.

Questions: open an issue on the GitHub repository.
